### 하루 리듬

오전 10시~오후 3시 사이에 절반(38/76건)이 몰려있고, 저녁 20~23시에 작은 2차 군집(12건). 낮엔 수업/시험, 밤엔 과제·시험공부로 설명 가능한 이중 피크.

### 각성 성격

### 만성 저조 (컨디션 난조)

28일 중 **4일** 저조 판정 — 7/05, 7/10, 7/27, 7/30. 특히 7/27·7/30은 안정시심박도 개인 평균보다 +8~9bpm 높아서 단순 하루 피로가 아니라 누적된 부담으로 읽힘.

### 대표 이벤트 (상황 복원 우선순위 후보)

1. **7/22 01:21 야간 급발현** — 심박 +37bpm 급등(자기 직전 시간대), 지속성 각성으로 회복도 느림.
2. **7/30 14:25 HRV 붕괴(14ms, 개인 평균 대비 절반)** — 만성 저조일(7/30)과 겹침.
